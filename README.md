## Tech Stack

- React 19 + TypeScript
- Three.js (3D visuals)
- Framer Motion (animations)
- Vite (build tool)

## Development

```bash
npm install
npm run dev
```

## Deployment

Pushes to `main` trigger automatic deployment via GitHub Actions to GitHub Pages.
